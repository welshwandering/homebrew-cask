# Homebrew Cask

Personal Homebrew tap for [@agh](https://github.com/agh).

## Usage

```bash
brew install agh/cask/cwtch
```

## Formulae

| Formula | Description |
|---------|-------------|
| `cwtch` | Manage Claude Code profiles and synchronise configuration from Git ([agh/cwtch](https://github.com/agh/cwtch)) |
